CSS 长度单位

Web 前端的长度单位分为绝对单位与相对单位；相对单位会随父元素、根字号或视口大小变化。

一、绝对单位（固定长度）

下面每根色条换算后都是 96px = 1in，长度完全相同：

二、相对单位

em：相对自身 font-size（写在 font-size 上则相对父元素）——父级字号变大，盒子跟着变：

父级 font-size: 16px → 子元素 width: 6em = 96px

width:6em

父级 font-size: 32px → 子元素 width: 6em = 192px

width:6em

rem：只相对根元素 html 的 font-size（默认 16px）——父级字号再怎么变都不影响：

父级 font-size: 16px → 子元素 width: 6rem = 96px

width:6rem

父级 font-size: 32px → 子元素 width: 6rem = 96px（两个盒子一样宽）

width:6rem

%：相对父元素的同一属性（宽度相对父宽）——拖动窗口看嵌套盒子一起缩放：

外层 width: 70%
中层 width: 50%（父的 1/2）
内层 width: 60%（中层的 6/10）

vw / vh：相对视口，1vw = 视口宽度的 1%，1vh = 视口高度的 1%——拖动浏览器窗口宽度试试：

width: 90vw
width: 50vw
width: 25vw
width: 60vw; height: 18vh

fr：Grid 轨道的剩余空间份额，只能用在 grid-template-columns/rows：

1fr
2fr
1fr

ch：数字 “0” 在当前字体下的宽度，常用于限制每行文本长度：

width: 20ch

三、单位速查表

类型 单位 基准 / 换算 说明
绝对单位 px 无（基本单位） 像素，网页中最常用
in 1in = 96px 英寸
cm 1cm ≈ 37.8px 厘米
mm 1mm ≈ 3.78px 毫米
pt 1pt = 1/72 in ≈ 1.33px 磅，常用于打印排版
pc 1pc = 12pt = 16px 派卡
相对单位 em 自身 font-size（font-size 则看父元素） 会层层叠加，适合弹性排版
rem 根元素 html 的 font-size 不受嵌套影响，适合整体缩放
% 父元素的同属性 响应式布局的基础
vw / vh 视口宽 / 高的 1% 相对浏览器窗口大小
vmin / vmax 视口较短 / 较长边的 1% 适配横竖屏切换
ch 字符 “0” 的宽度 控制每行字符数
ex 小写字母 x 的高度 较少使用
fr Grid 剩余空间的份额 仅限 grid 轨道
