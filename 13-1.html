Font Awesome 字体图标

字体图标：图标被做成了一套字体文件（woff2 / ttf），通过 CSS 的 @font-face 加载，
页面上写一个 <i> 标签 + 类名，图标就作为一个「字符」显示出来，颜色、大小都用 CSS 控制。

四、使用方法

<!-- 1. 先引入本地样式文件（字体文件放在 cdn/font-awesome/webfonts/ 里） --> <link rel="stylesheet" href="cdn/font-awesome/css/all.min.css"> <!-- 2. 一个 i 标签 + 前缀类名 + 图标类名 --> <i class="fa-solid fa-house"></i> 实心图标 <i class="fa-regular fa-heart"></i> 常规图标 <i class="fa-brands fa-github"></i> 品牌图标 <!-- 3. 颜色和大小用 CSS 控制，和文字完全一样 --> <style> .fa-house{ font-size: 32px; color: #4a90e2; } </style>
