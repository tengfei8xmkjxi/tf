Lucide SVG 图标

SVG 图标：每个图标都是一段矢量图形代码，页面上写一个带 data-lucide 属性的占位标签，
由本地引入的 lucide.min.js 把它替换成真正的 <svg> 元素，缩放不失真，颜色、线宽都可以用 CSS 控制。

三、使用方法

<!-- 1. 引入本地下载的 lucide（会挂到 window.lucide 上） --> <script src="cdn/lucide/lucide.min.js"></script> <!-- 2. 写一个带 data-lucide 属性的标签，属性值就是图标名 --> <i data-lucide="house"></i> <i data-lucide="shopping-cart"></i> <!-- 3. 调用 createIcons()，上面的标签会被替换成内联 svg --> <script> lucide.createIcons(); </script> <!-- 4. 生成出来的结构大致是这样，可以直接用 CSS 设置大小、颜色、线宽 --> <svg class="lucide lucide-house" width="24" height="24" viewBox="0 0 24 24" fill="none" stroke="currentColor" stroke-width="2" ...> <path d="..."></path> </svg> <style> .lucide{ width: 32px; height: 32px; color: #4a90e2; stroke-width: 1.8; } </style>
