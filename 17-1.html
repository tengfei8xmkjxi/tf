24001010528 滕菲：JSON —— 数据的书写格式

JSON（JavaScript Object Notation）是一种纯文本的数据格式：{} 表示对象，[] 表示数组， 键名必须写成双引号。它和编程语言无关，浏览器、服务器、手机都能读，所以接口传数据几乎都用 JSON。 本页把「一段 JSON 字符串」和「它解析出来的对象」对着展示。

① 只有两种结构对象 {} 是无序的键值对，数组 [] 是值的有序列表
② 只有六种值字符串、数字、布尔、null、对象、数组；没有 undefined，也没有函数
③ 语法很严格键名和字符串必须用双引号，最后一项后面不能多写逗号

一、一段 JSON 长什么样

下面这段文本是 JSON.stringify(数据, null, 2) 的输出，第三个参数 2 表示用 2 个空格缩进， 所以人能一眼看出层级。字符串里没有颜色、没有样式，只有"键"和"值"。 



    
二、JSON.parse()：字符串 → 对象

    

        接口返回的响应体是一段字符串，要先 parse 成对象，才能用点号取值、用 length 数个数。
        这一步不做，data.works 只会得到 undefined。
    

    

        
// jsonText 就是上面那段字符串
var data = JSON.parse(jsonText);

console.log(typeof jsonText);   // "string"
console.log(typeof data);       // "object"
console.log(data.works[1].title);

        

    


    
三、JSON.stringify()：对象 → 字符串

    

        方向反过来：把对象变成字符串，才能存进 localStorage、写进文件或者发送给服务器。
        省略第三个参数就是一行到底，适合传输；带上缩进就是给人阅读的格式。
    

    

        
// 不带缩进：一行到底，适合传输
var oneLine = JSON.stringify(data);

// 带缩进：给人看的格式
var pretty = JSON.stringify(data, null, 2);

        

    


    
四、用 JSON 数据点出表格

    

        JSON 只是数据，页面上长什么样要靠 DOM 决定。下面把 data.works 这个数组循环成表格行，
        数组有几项，表格就有几行。
    

    

        
var rows = "";
for (var i = 0; i < data.works.length; i++) {
    var w = data.works[i];
    rows += "<tr><td>" + w.page + "</td>"
          + "<td>" + w.title + "</td>"
          + "<td>" + w.file + "</td></tr>";
}
document.getElementById("work-table").innerHTML = rows;

五、parse 会抛错，所以要用 try…catch

    

        下面这段故意写错：键名 student 没有加双引号。JSON.parse 遇到不合法的格式会直接抛
        SyntaxError，如果不用 try…catch 接住，后面的代码就全部停住了。
    

    

        
var text = '{student: "滕菲", score: 95}';   // 错：键名少了双引号

try {
    var obj = JSON.parse(text);
    console.log("解析成功", obj);
} catch (err) {
    console.log(err.name);      // SyntaxError
    console.log(err.message);   // 告诉你错在第几个字符
}
