24001010528 滕菲：用 fetch 取一个接口的数据

接口就是一个会返回 JSON 的网址。fetch() 是浏览器自带的函数，不需要引任何库， 给它一个地址就返回一个 Promise；请求回来后再用 res.json() 把响应体读成对象。 本页所有数据都是页面打开时从接口实时取回来的。

GET https://dummyjson.com/quotes/random 返回 { id, quote, author }
① fetch(url)发出请求，马上得到一个 Promise
② res.json()把响应体读出来，转成 JS 对象
③ then / catch成功在 then 里渲染，失败在 catch 里提示

下面就是这段效果的全部代码：res.ok 用来判断 HTTP 状态码是不是 2xx， Date.now() 前后相减得到这次请求的耗时。 

var API = "https://dummyjson.com/quotes/random";

fetch(API)
    .then(function (res) {
        if (!res.ok) {                        // 404、500 都算失败
            throw new Error("HTTP " + res.status);
        }
        return res.json();                    // 响应体 → 对象
    })
    .then(function (data) {
        box.innerHTML = "<blockquote>" + data.quote + "</blockquote>";
    })
    .catch(function (err) {
        box.innerHTML = "请求失败：" + err.message;
    })
    .finally(function () {
        button.disabled = false;              // 不管成功失败都恢复按钮
    });

二、404 也要自己判断

这是 fetch 最容易踩的坑：只有断网、域名写错这类网络层错误才会进 catch， 服务器返回 404 / 500 时照样进 then，必须自己看 res.ok。

点一下按钮：https://dummyjson.com/products/99999 会返回 404，看看它进 then 还是 catch。

三、同样的逻辑，async / await 写法

用 async / await 可以把 Promise 写成同步的样子，try…catch 同时接住网络错误和 HTTP 错误。

async function loadQuote() {
    try {
        var res = await fetch(API);
        if (!res.ok) {
            throw new Error("HTTP " + res.status);
        }
        var data = await res.json();
        render(data);            // 拿到数据再渲染
    } catch (err) {
        showError(err);          // 任何一步出错都到这里
    }
}
