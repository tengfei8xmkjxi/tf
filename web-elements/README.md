## 七、实现过程中卡住的点（可直接写进总结）

1. **首屏高度用 `100svh` 而不是 `100vh`** —— 移动端浏览器地址栏展开/收起时 `100vh` 会让首屏跳动，`svh` 取的是最小可视高度，稳定不闪。
2. **柱状图的月份文字把柱子挤出绘图区** —— 一开始柱子高度写 `height: var(--tf-h)`、月份文字用 `margin-top` 放在 flex 流里，柱 + 文字总高超过容器，柱子顶部被顶出网格。改成月份文字 `position: absolute` 定位到绘图区下内边距里，柱高百分比才算准。
3. **无 JS 时图表会一片空白** —— 柱子默认 `transform: scaleY(0)`，如果脚本没跑就永远是 0。改为只有 `<html>` 带 `tf-js` 类时才压扁（该类由头部内联脚本添加），保证禁用 JS 时图表依然完整显示。
4. **触屏没有 hover** —— 卡片悬浮态在手机上永远触发不了，补了 `:active` 的轻微回弹，避免"点了没反应"的观感。
5. **键盘可访问** —— 用 `:focus-within` 让 Tab 聚焦卡片内按钮时触发同一套悬浮样式，不只依赖鼠标。
