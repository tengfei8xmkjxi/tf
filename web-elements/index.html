02 / Hover Card

图文悬浮卡片

鼠标移入或键盘聚焦时，卡片整体上浮、图片缓慢放大、底部下划线自左向右展开。 三张卡片同时覆盖「图片卡」与「纯色渐变卡」两种排版，只靠一套 class 完成。

城市飞行计划

以一张航拍主视觉串起整套海报、导视与线上触点，让品牌在每一次曝光里保持同一种呼吸节奏。

会晤空间

把品牌调性搬进线下空间，用材质、光线与动线讲同一个故事，屏幕上与现场不再割裂。

03

数据与节奏

真正决定页面质感的，是留白、层级与动效的节奏。 第三张卡片不用图片，用深色渐变承接版式，让视线在整行里有一个落点。

03 / Data

数字滚动统计

四个数字进入视口后从 0 滚动到目标值；下方柱状图不借助图表库、不用 canvas， 柱高由 CSS 变量 --tf-h 驱动，进视口后按 70ms 的间隔依次生长。
